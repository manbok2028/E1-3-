# E1-3 Mini NPU Simulator 평가 보고서

## 1. 한눈에 보는 결과물

이 결과물은 사람이 보는 Cross(십자가)와 X 모양을 숫자 행렬로 바꾸고, 두 필터의 MAC 점수를 비교하는 Python 콘솔 프로그램입니다. AI가 이미지 패턴을 살필 때 쓰는 “곱하고 더하기”의 핵심을 아주 작은 크기로 재현했습니다. 외부 라이브러리 없이 Python 표준 라이브러리만 사용했습니다.

## 2. 미션 목표와 구현 연결

| 미션 목표 | 초등학생도 이해할 설명 | 구현 위치 |
| --- | --- | --- |
| MAC 이해 | 같은 자리의 숫자를 곱해 모두 더한 점수로 모양이 얼마나 닮았는지 확인한다. | `npu.py`의 `mac_score()` |
| 필터 유사도 | Cross 필터 점수와 X 필터 점수를 비교해 더 큰 쪽을 선택한다. | `decide_label()` |
| 라벨 규칙 | `+`, `cross`, `x`처럼 표기가 달라도 두 가지 표준 이름으로 통일한다. | `normalize_label()` |
| 소수점 안전성 | 거의 같은 점수는 계산 오차일 수 있으므로 `1e-9` 안에서는 동점으로 본다. | `EPSILON`, `decide_label()` |
| O(N²) 분석 | N×N 칸을 모두 한 번 방문하므로 칸 수 N²만큼 일이 늘어난다. | `measure_mac()`, 성능 표 |
| 실패 진단 | 잘못된 데이터는 멈추지 않고 데이터/스키마·크기·숫자 문제라는 사유와 함께 FAIL로 남긴다. | `analyze_data()` |

## 3. 필수 요구사항 충족표

| 요구사항 | 수행 방법 | 확인 방법 |
| --- | --- | --- |
| 3×3 직접 입력 | A/B 필터와 패턴을 세 줄씩 입력받는다. | 메뉴 1 |
| 입력 검증·재입력 | 행별 숫자 3개 여부와 숫자 변환을 검사하고 틀리면 행렬을 처음부터 다시 입력받는다. | 메뉴 1의 오류 안내 |
| 5·13·25 크기 | `data.json`에 세 크기의 2차원 필터·패턴을 제공한다. | 메뉴 2 |
| 키에서 크기 선택 | `size_{N}_{idx}`에서 N을 추출해 `size_N` 필터를 연결한다. | `extract_size_from_key()` |
| 정규화 | expected `+`/`x`, filter `cross`/`x`를 `Cross`/`X`로 통일한다. | 분석 출력 |
| 반복문 MAC | 중첩 `for`로 직접 곱하고 누적한다. | `mac_score()` |
| epsilon 동점 | `abs(a-b) < 1e-9`이면 UNDECIDED다. | 단위 테스트 |
| 10회 평균 성능 | 각 크기에서 10회 이상 함수 호출만 재어 평균 ms와 N²를 출력한다. | 메뉴 1·2 |
| 요약 리포트 | 총/통과/실패와 실패 식별자·사유를 출력한다. | 메뉴 2 |
| README 결과 보고 | 실패 원인과 O(N²) 근거를 10줄 이상 기록했다. | `README.md` 5장 |

## 4. 보너스 구현

1. `generate_cross()`와 `generate_x()`는 원하는 홀수 크기의 패턴을 자동 생성합니다.
2. `flatten()`과 `mac_score_flat()`은 행렬을 1차원으로 펼쳐 같은 MAC 점수를 계산합니다.
3. 메뉴 3은 같은 입력과 반복 횟수로 2차원 방식과 1차원 방식을 비교합니다. 빠르다는 결론을 미리 정하지 않고, 실행한 컴퓨터에서 측정된 평균만 보여 줍니다.

## 6. 평가 재현 절차

```powershell
python -m unittest discover -s tests -v
python main.py
# 메뉴에서 2를 입력해 JSON 분석 결과와 성능 표를 확인
```

정상 `data.json`은 모든 케이스가 PASS가 되어야 합니다. 일부러 크기를 바꾸거나 라벨을 망가뜨렸다면 프로그램 전체가 멈추지 않고 해당 케이스가 FAIL이 됩니다. 이것이 “데이터가 나쁘다”와 “프로그램 로직이 나쁘다”를 구분하는 출발점입니다.
